# 英语通行手册 · 旅行与日常生活

45个场景任务：21课旅行、10课日常交流基础、14课日常生活进阶。

从机场、酒店、交通、点餐与购物，练到邻里聊天、邀请朋友、表达感受、电话预约和完整生活日交流。

新增生活第11–24课包含84句重点表达、14段对话、42次接话练习、14道情境题和4段短文。支持逐句重播、中英讲解、慢速与正常语速、点词解释和带中文的笔记。

公网首屏为轻量HTML，音频按点击加载。音频文件名带内容哈希，避免更新课程后缓存错配。
