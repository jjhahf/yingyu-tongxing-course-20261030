  4. 最后做两道选择题、看中文说英文，并录一段自己的到达对话。

今天可分两次学，每次约 30 分钟。第一遍重在听懂，第二遍重在自己说。

AI 产品经理常用词

use case

使用场景

讨论一个具体用户任务时使用。
user journey

用户旅程

用户从开始到完成任务的过程。
requirement

需求

产品需要满足的条件或功能。
must-have

必须有的

当前阶段不可缺少的需求。

模型

prompt

提示词
